Welcome to Takir

                
A medieval-flavoured skill and quest tracker. Build a character sheet, take quizzes, and let Tak (the AI) plan your next adventure.

                
Three views, all yours:

                
    
                    
  • Skills — things you know (e.g. Swordsmanship, Rust, Sourdough).
    • 
                    
  • Quests — things to do, with prerequisite trees and progress uploads.
    • 
                    
  • Learn — chat with Tak about anything. He can search the web and recommend free resources.
    • 
                

                
Everything works offline. The AI features need an OpenRouter API key (free tier available).
